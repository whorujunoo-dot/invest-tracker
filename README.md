# 기록소

텔레그램으로 남긴 생각·경험·자료를 원본 그대로 영구 보관하고, 시간이 지나 다시 찾고 비교할 수 있게 하는 개인 기록 시스템.

## 지금 되는 것 (1단계: 수집·보존)

- 텔레그램 봇으로 음성, 글, 사진, 링크, 파일 수집. `#태그` 자동 인식
- 받는 즉시 원 메시지와 파일을 원본 저장소에 보관 (같은 내용은 한 번만, SHA-256으로 확인)
- 음성 → 받아쓰기 → 문맥 교정. 고친 곳은 모두 표시되고, 원문으로 되돌려 대조할 수 있는지 자동 검사
- 사진 속 글자 읽기, 링크 본문 사본 보관
- 웹: 날짜별 흐름, 검색, 상세(원문 · 교정본 · 처리 결과 구분), 고친 판 이력, 휴지통, 단어장
- 매일 암호화 백업, 매월 실제 복구 검증, 마크다운 내보내기. 결과는 텔레그램으로 보고

## 원칙

1. 원본은 데이터베이스 단계에서 수정·삭제가 막혀 있다
2. AI 결과는 언제든 다시 만들 수 있는 부산물로, 모델·지침 버전과 함께 별도 저장
3. 데이터는 열린 형식(PostgreSQL, S3, 마크다운)이라 어느 업체로든 옮길 수 있다
